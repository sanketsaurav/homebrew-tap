Personal Homebrew tap.

| Package | Install | What it is |
| --- | --- | --- |
| [portia](https://portia.sh) | `brew install sanketsaurav/tap/portia` | Local, web-based code review built for AI coding agents |
| Portia.app | `brew install --cask sanketsaurav/tap/portia` | macOS desktop shell for the same UI |
| [museletter](https://github.com/sanketsaurav/museletter) | `brew install sanketsaurav/tap/museletter` | Headless, agent-first newsletter engine using SQLite and Amazon SES |

Formulae and casks in this tap are regenerated by each project's release
workflow on tagged releases — don't edit them by hand.
